## Homework Assignment

Participants were asked to complete four tasks:

1. **GitHub Registration:** Register on GitHub - CalTRACK-2
2. **Documentation Review:** Study CalTRACK.org and docs.caltrack.org for historical context
3. **Meeting Scheduling:** Respond to a Doodle poll to establish recurring meeting times
4. **Issue Tracking:** Submit specific concerns on the GitHub CalTRACK-2 Issues page

## Key Resources Referenced

The post directed participants toward several important platforms:
- GitHub repository for code collaboration and issue tracking
- Documentation sites preserving prior decisions and technical content
- Meeting recordings archive showing previous sessions from February through July 2018

The post emphasized collaborative problem-solving through GitHub and established standardized communication channels for the technical working group.
